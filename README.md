# portfolio

Сайт-портфолио Анны Даниловой, графического дизайнера и AI-креатора: мерч, упаковка, промопродукция и AI-визуал.

Статический одностраничный сайт (HTML, CSS, vanilla JS) для публикации на GitHub Pages. Сборка не нужна.

## Структура

```
index.html          разметка и тексты
styles.css          стили (тёмная тема по умолчанию + светлая по кнопке)
script.js           тема, появление секций, счётчики, модалка
assets/favicon.svg
assets/og.jpg       превью для соцсетей 1200×630
assets/ai/          логотипы AI-инструментов (lobehub/icons, MIT)
assets/clients/     логотипы компаний
assets/works/       изображения работ
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты сайт будет по адресу https://aadanilova.github.io/portfolio/

## Темы

По умолчанию тёмная тема, как в референсе. Кнопка-кружок в шапке включает светлую (выбор запоминается в localStorage).

## Типографика

В текстах после коротких предлогов и союзов стоят неразрывные пробелы (`&nbsp;`), чтобы они не висели в конце строки. При правке текстов сохраняйте это правило.

## Карточки работ

Все проекты лежат одной сеткой `.cases` в секции `#works`. В карточке заголовок — компания (или тип работы, если компании нет), описание — сам проект.
Контекст работы и инструменты видны только в модалке и задаются атрибутами карточки:

```html
<article class="case" data-tilt data-context="H-ONE · мерч" data-tools="Illustrator, Photoshop">
```

Текст и галерея модалки лежат в `<template class="case__details">` внутри карточки. Классы галереи: `gallery` (одна колонка), `gallery--two` (две колонки), `gallery--grid` (авто-сетка), `gallery--postcards` (2 + 2 + 1 по центру).
