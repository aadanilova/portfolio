# portfolio

Сайт-портфолио Анны Даниловой, графического дизайнера: концепции, айдентика, упаковка, промо и digital.

Статический одностраничный сайт (HTML, CSS, vanilla JS) для публикации на GitHub Pages. Сборка не нужна.

## Дизайн

Минималистичная редакционная вёрстка по референсу: тёмный фон, крупный гротеск Inter Tight (Google Fonts, кириллица), тонкие линии и подписи капсом.

Секции: hero «→ Портфолио», 01 Обо мне, 02 Проекты, 03 Навыки, 04 Опыт работы, 05 Образование, 06 Контакты. Каждая секция начинается одинаково: строка «Портфолио … NN» и крупный заголовок `.display`.

Анимации: стрелка в hero прорисовывается, слово выезжает из-под маски, секции плавно появляются при скролле, цифры набираются счётчиком. При `prefers-reduced-motion` всё движение отключено.

## Структура

```
index.html          разметка и тексты
styles.css          стили (тёмная тема по умолчанию + светлая по кнопке)
script.js           тема, появление секций, счётчики, модалка
assets/favicon.svg
assets/og.jpg       превью для соцсетей 1200×630
assets/photo.jpg    фото в блоке «Обо мне», один горизонтальный файл (1536×1024): показывается целиком в кадре 3:2, на десктопе колонки фото и текста поровну
assets/Anna_Danilova_CV.pdf  резюме для кнопок «Скачать резюме» (hero и «Контакты»)
assets/works/       изображения работ
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты сайт будет по адресу https://aadanilova.github.io/portfolio/

## Темы

По умолчанию тёмная тема, как в референсе. Кнопка-кружок в шапке включает светлую (выбор запоминается в localStorage).

## Резюме (PDF)

Ссылка «Резюме в PDF ↓» есть в hero (третьей строкой контактов) и в «Контактах». Обе ссылаются на `assets/Anna_Danilova_CV.pdf`. Чтобы обновить резюме, замените файл с тем же именем (только латиница). Если файл удалить, уберите и обе ссылки.

## Цифры

Анимация набора есть только у «80+» и «100+»; «2,5+» и «7/10» показываются сразу. Счётчики задаются атрибутами `data-count`, `data-suffix`, `data-prefix`, для дробных чисел `data-decimals` (например, `data-count="2.5" data-decimals="1"` → «2,5»). Приглушённая часть, как «/10», — отдельный `<span class="stat__num-muted">`.

## Компании

Блок `.clients` стоит сразу под цифрами в «Обо мне» и повторяет их сетку (2 колонки от 768px, 4 от 1024px): подпись под первой цифрой, названия со второй колонки, размер `--fs-title`, разделители «/» приглушённые. На мобильном подпись над названиями. Названия клиентов требуют проверки NDA (см. комментарий в разметке).

## Мобильная версия (< 768px)

Меню — второй строкой в шапке с горизонтальным скроллом. Hero короче: имя и роль, теги, ссылки «Смотреть проекты» и «Связаться», контакты и год «2026» на мобильном скрыты (почта, hh.ru и PDF есть в блоке «Контакты»). Ссылки в hero и меню имеют тап-зону не меньше 44px.

## Типографика

Шрифт один: Inter Tight. Обычный текст использует только четыре размера (токены в `:root` в `styles.css`):

| токен | размер | где |
|---|---|---|
| `--fs-caption` | 13px | капс-подписи, меню, «Портфолио 01», метки |
| `--fs-small` | 15px | вторичный текст: подписи цифр, описания кейсов и навыков, даты, ссылки контактов в hero |
| `--fs-body` | 16–18px | весь основной текст абзацами |
| `--fs-title` | 22px | клиент в карточке кейса |

Крупные заголовки, цифры и контакты внизу страницы задаются отдельно. Цвет: абзацы всегда основным цветом (`--text`), серый (`--muted`) только для подписей, меток, дат и описаний в карточках.

В текстах после коротких предлогов и союзов стоят неразрывные пробелы (`&nbsp;`), чтобы они не висели в конце строки. При правке текстов сохраняйте это правило.

## Карточки работ

Все проекты лежат одной сеткой `.cases` в секции `#works` (2 колонки, номер карточки ставится автоматически). В карточке заголовок — компания (или тип работы, если компании нет), описание — сам проект.
Контекст работы и инструменты видны только в модалке и задаются атрибутами карточки:

```html
<article class="case" data-context="H-ONE · мерч" data-tools="Illustrator, Photoshop">
```

Текст и галерея модалки лежат в `<template class="case__details">` внутри карточки. Классы галереи: `gallery` (одна колонка), `gallery--two` (две колонки), `gallery--grid` (авто-сетка), `gallery--postcards` (2 + 2 + 1 по центру).
